# Welcome to HCiw's documentation

HCiw is a discrete event simulation library for open queueing networks, forked
from the [Ciw](https://github.com/CiwPython/Ciw) library. Its core features
include the capability to simulate networks of queues, multiple customer
classes, and implementation of Type I blocking for restricted networks. A
number of other features are also implemented, including priorities, baulking,
reneging, schedules, slotted services, batch arrivals, service disciplines,
dynamic customer classes, and deadlock detection.

The name **HCiw** takes the **H** from healthcare (the project was originally a
healthcare-oriented wrapper around Ciw) and combines it with **Ciw**, the Welsh
word for a queue.

HCiw is a fork of Ciw: the code is a continuation of the Ciw 3.2.7 codebase,
released under the same MIT licence, and credits the Ciw contributors in
[the authors page](Project/authors.md).

HCiw is currently supported for and regularly tested on Python 3.12.
